# Contribution at DCT

As an author the user can repair or contribute new code/documentation and
make these changes available for other project members.


## DCT

The general user manual defines some
[author use cases](https://gerrit.office.dreamchip.de/plugins/gitiles/it/git/user/+/refs/heads/main/README.md#Author-use-cases)
that are not specific to this project.

The [`README.md`](README.md) of this project is the entry point for new (and
existing) users.  Additional documentation may be offerered in Markdown format,
too.  The Gerrit server renders such files directly, for all
branches/tags/commits - including different versions of a Gerrit change. Refer to the
[Markdown flavor of Gitiles](https://github.com/google/gitiles/blob/master/Documentation/markdown.md)
for syntax details.
